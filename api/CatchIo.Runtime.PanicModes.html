    Namespace CatchIo.Runtime.PanicModes

    Classes

    CharacterPanicListener

    CharacterPanicListener manages panic states for a character that can be targeted by multiple aggressors.

    Core Responsibilities:

    • Track multiple aggressors through their ViewIDs
    • Manage panic state transitions and sound effects
    • Handle network synchronization of panic states
    • Manage cleanup on death/destruction

    Panic State Management:

    • Multiple aggressors can induce panic simultaneously
    • Each aggressor is tracked by unique ViewID
    • Sound effects are managed based on aggressor count
    • Network sync can be optionally disabled for local operations

    Key Features:

    • Thread-safe aggressor tracking using HashSet
    • Event-based network synchronization
    • Automatic cleanup on death
    • Reference counting for sound effect management

    CharacterPanicSfxEmitter

    Specialized panic sound effect emitter for character-specific behaviors.

    Extends the base EntityPanicSfxEmitter with character-specific logic:

    • Tracks character facade for additional context
    • Handles sound effect interruption on character death

    Key Responsibilities:

    • Manage panic sound effects for characters
    • Automatically stop sound effects when character dies
    • Maintain connection with character lifecycle events

    CharacterPanicTrigger

    CharacterPanicTrigger manages the panic inducing system in a multiplayer environment.

    Core Responsibilities:

    • Detects and manages potential targets within field of view
    • Handles panic state transitions with induction/escape delays
    • Processes network events for panic state synchronization
    • Manages panic state changes across the network

    States:

    • No Target: No current target (_targetInPanic == null)
    • Inducing Panic: Target set but waiting for induction timer
    • Active Panic: Target in panic state and synchronized across network
    • Escaping Panic: Target leaving FOV, waiting for escape timer

    Key Features:

    • FOV-based target detection using hitboxes
    • Timer-based induction/escape delays
    • Network event handling (death, disconnect, transmorph)
    • Multiplayer synchronization through Photon
