    Class PanicStateSfx

    Manages sound effects for Panic state changes in the game.

    Key Responsibilities:

    • Play spatial 3D sound effects for Panic activation and deactivation
    • Map Panic states to specific sound variations
    • Provide volume and positioning control

    Design Patterns:

    • State mapping
    • Spatial audio implementation

    Features:

    • Enum-based Panic state selection
    • 3D sound positioning
    • Volume customization

    Use Cases:

    • Providing audio feedback for panic mode changes
    • Spatial sound effects for game interactions
