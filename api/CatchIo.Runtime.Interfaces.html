    Namespace CatchIo.Runtime.Interfaces

    Interfaces

    ICharacterDetectable

    Interface for character detecting, providing methods for handling detection and missing events. Each character implementing this interface has a unique ViewID for identification in networked environment.

    IDamageInterceptable

    IDetectable

    IEntityMarkBlockable

    IEntityScoutingMarkable

    Defines an interface for entities that can be marked as part of the scouting system. Entities implementing this interface support being marked and provide positional data.

    IEntityTrapBlockable

    IHasSilhouetteMask

    IHUDDisplayable

    Defines an interface for entities that support HUD display functionality. Entities implementing this interface can provide HUD positioning and toggle visibility.

    IItemImpact

    Interface for defining impact effects that can be applied to a target or at a specific position. Implementing classes can specify different types of effects such as damage, buffs, or summoning.

    IItemImpactable

    Interface for objects that can receive impact effects, such as damage or status effects, from items. Defines events and methods for managing impacts, allowing for interaction with IItemImpact.

    IMarkingEntity

    IPanickable

    Defines the contract for objects that can enter panic mode when targeted by other players.

    This interface provides methods and properties for handling panic state events and identifying the network-specific details of a panickable entity.

    Key Responsibilities:

    • Provide network identification (ViewID and ActorNumber)
    • Handle panic state transitions triggered by other players

    IPositionProvider

    Provides an interface for objects that can supply positional information.

    ISceneMode

    ISoundDetectable

    ISoundWaveDetectionMediator

    Mediator interface for managing sound wave detection distance modifications. Coordinates between sound detectors and distance modifiers

    ISoundWaveDistanceModifier

    Interface for modifying sound wave detection distances. Implements the strategy pattern for different distance modification calculations.
