    Class CharacterPanicTrigger

    CharacterPanicTrigger manages the panic inducing system in a multiplayer environment.

    Core Responsibilities:

    • Detects and manages potential targets within field of view
    • Handles panic state transitions with induction/escape delays
    • Processes network events for panic state synchronization
    • Manages panic state changes across the network

    States:

    • No Target: No current target (_targetInPanic == null)
    • Inducing Panic: Target set but waiting for induction timer
    • Active Panic: Target in panic state and synchronized across network
    • Escaping Panic: Target leaving FOV, waiting for escape timer

    Key Features:

    • FOV-based target detection using hitboxes
    • Timer-based induction/escape delays
    • Network event handling (death, disconnect, transmorph)
    • Multiplayer synchronization through Photon
