    Interface IMoveProcessor

    Interface for processors that participate in the movement calculation pipeline. Each processor can modify the movement context and then pass control to the next processor.

    Namespace: CatchIo.Runtime.Interfaces
    Assembly: cs.temp.dll.dll
    Syntax
    public interface IMoveProcessor

    Properties

    Priority

    The execution priority of this processor in the pipeline. Processors with lower priority values execute first.

    Declaration
    int Priority { get; }
    Property Value
    Type Description
    System.Int32

    Methods

    Process(MoveContext, Action<MoveContext>)

    Processes the movement context and modifies it according to the processor's logic.

    Declaration
    void Process(MoveContext context, Action<MoveContext> next)
    Parameters
    Type Name Description
    MoveContext context

    The shared movement context to process.
    System.Action<MoveContext> next

    Callback to invoke the next processor in the chain.
    Remarks

    Each processor should perform its calculations on the context and then call the 'next' action to continue the processing chain, unless it intentionally wants to terminate the chain.
