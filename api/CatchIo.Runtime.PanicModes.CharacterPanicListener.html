    Class CharacterPanicListener

    CharacterPanicListener manages panic states for a character that can be targeted by multiple aggressors.

    Core Responsibilities:

    • Track multiple aggressors through their ViewIDs
    • Manage panic state transitions and sound effects
    • Handle network synchronization of panic states
    • Manage cleanup on death/destruction

    Panic State Management:

    • Multiple aggressors can induce panic simultaneously
    • Each aggressor is tracked by unique ViewID
    • Sound effects are managed based on aggressor count
    • Network sync can be optionally disabled for local operations

    Key Features:

    • Thread-safe aggressor tracking using HashSet
    • Event-based network synchronization
    • Automatic cleanup on death
    • Reference counting for sound effect management
