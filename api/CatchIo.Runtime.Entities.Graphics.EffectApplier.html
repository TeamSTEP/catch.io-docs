    Type Description

    Remarks

    This method handles the complete lifecycle of an effect:

    1. Validates the effect data
    2. Sets up required resources (material, tweens)
    3. Executes the effect animation
    4. Cleans up resources when complete If an effect with the same data is already playing, if will be canceled before the new instance starts

    Remarks

    Rewinding an effect:

    1. Validates the effect is currently active
    2. Plays all animations in reverse
    3. Removes the effect and cleans up resources If the effect is not currently active, the operation is skipped
