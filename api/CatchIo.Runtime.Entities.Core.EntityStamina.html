    Class EntityStamina

    Manages entity stamina system with network-aware consumption and recovery.

    Core Responsibilities:

    • Track current and maximum stamina values
    • Handle stamina consumption requests across network
    • Process stamina recovery
    • Manage stamina-related events

    Network Features:

    • Owner-based stamina modification
    • Network request handling through events
    • Threshold-based value handling
